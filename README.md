# 邏輯工坊

供大專工科、資電與通識初學者使用的網頁教具。五個模組共 24 道互動關卡，其中 16 道為電路接線題。內容從邏輯閘、布林代數與 K-Map，進入組合電路、循序邏輯及自由連線沙盒。每關提供即時檢核、提示與詳解；完成模組可獲得徽章。

專案儲存庫：[Yuan-Chun-Chih/LogicLab](https://github.com/Yuan-Chun-Chih/LogicLab)。歡迎點亮我們的專案！

## 啟動

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址（通常是 `http://localhost:5173/`）。

## 操作方式

- 首頁可從「學習路線」選擇模組，也能點擊示範電路的 A、B 觀察 AND 輸出。闖關時，左上角按鈕可展開選擇關卡側欄。
- 電路題可以從元件列拖入邏輯閘，或點選元件快速加入。每種閘使用對應的電路符號。
- 連線可從來源接點拖到目的接點，也可依序點選來源、目的接點。邏輯閘右上角常駐小垃圾桶可直接刪除該閘；導線選取後可使用刪除按鈕。選取後也可按 Delete 或 Backspace。
- 題目提供的輸入與輸出端也能個別拖曳。點擊 INPUT 元件內的 0／1 開關即可切換輸入，輸出結果顯示在 OUTPUT 元件內。
- 切換輸入即可即時觀察輸出：0 顯示藍灰、1 顯示青綠、未知訊號 X 顯示琥珀色與虛線。導線依來源訊號變色，元件依輸出訊號變色；邏輯閘的輸出值顯示在符號內。
- 闖關頁採分層深色介面，讓電路畫布、任務卡與提示保持清楚的視覺層級；高電位訊號會沿導線流動。輸入切換、接線及檢核有短音效，右上角喇叭按鈕可關閉音效，設定會保存在目前瀏覽器。
- 桌面版接線關卡會在視窗內顯示工作台和主要檢核按鈕；提示與詳解可在右側任務卡內捲動。窄螢幕保留底部固定的檢核按鈕。
- 按「逐列演示」可依序播放本關的輸入組合，查看每列的預期與實際輸出。演示中會暫停編輯；若有錯誤，結束後會停在第一組失敗輸入，並標示錯誤輸出。可按「停止演示」還原開始前的輸入狀態。
- 按「測試電路」會逐組檢查所有輸入；循序題則會檢查多個時間點。通關後主按鈕會變成「下一關」；修改電路或答案後需重新測試。
- 工作台上方有「復原／重做」，也可用 `Ctrl+Z`／`Ctrl+Shift+Z`（Mac 用 `⌘`）。新增、刪除、連線、移動、清空與輸入切換都能回到前一步；新操作會清除重做紀錄。
- 測試失敗時，工作台顯示第一組錯誤輸入及預期、實際輸出，並標亮對應輸出；循序題會標示失敗的時間步驟。
- 手機版底部固定測試按鈕。工作台有固定邊界，最多放置 8 個元件；拖曳元件離開可見區域時會移回畫布。「顯示全圖」可快速找回所有元件。自由探索工作台可產生目前電路的真值表。

## 檢查

```bash
npm run build
npm run smoke
```

`smoke` 使用本機安裝的 Google Chrome，驗證答題與進度保存、電路求值、點選接線，以及桌面和手機版流程。

## 實作結構

- `src/content.ts`：模組、24 道題目、提示、詳解、16 道接線題的連接順序與電路目標。
- `src/logic.ts`：邏輯閘與 D 正反器求值、真值表與自動檢核。
- `src/GateSymbol.tsx`：AND、OR、XOR、NAND、NOT 與 D 正反器 SVG 符號。
- `src/Workbench.tsx`：拖放元件、接線、個別刪除、視角限制及即時輸入。
- `src/SignalEdge.tsx`：訊號導線及選取後的刪除工具列。
- `src/sound.ts`：可關閉的合成互動音效。
- `src/App.tsx`：首頁、闖關流程、評量回饋、進度與徽章。
- `src/styles.css`：桌面與手機版樣式。

學習進度保存在目前瀏覽器的 `localStorage`，不會跨裝置同步。自由探索工作台提供兩個輸入、一個輸出的組合邏輯；循序電路的 D 正反器練習位於循序邏輯模組。
