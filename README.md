# 邏輯工坊

供大專工科、資電與通識初學者使用的網頁教具。五個模組共 40 道互動關卡，其中 27 道為電路接線題。內容從邏輯閘、布林代數與 K-Map，進入組合電路、循序邏輯及自由連線沙盒。每關提供即時檢核、提示與詳解；完成模組可獲得徽章。

專案儲存庫：[Yuan-Chun-Chih/LogicLab](https://github.com/Yuan-Chun-Chih/LogicLab)。歡迎點亮我們的專案！

線上體驗：[邏輯工坊](https://yuan-chun-chih.github.io/LogicLab/)。

## 啟動

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址（通常是 `http://localhost:5173/LogicLab/`）。

## 操作方式

- 首頁可從「學習路線」選擇模組，也能點擊示範電路的 A、B 觀察 AND 輸出。闖關時，左上角按鈕可展開選擇關卡側欄。
- 側邊欄提供「選擇關卡／邏輯閘／常見公式」三個分頁。可隨時查閱 AND、OR、NOT、NAND、NOR、XOR、XNOR 與 D 正反器的符號、介紹與真值表，並操作獨立的輸入示範；查閱不會改變目前答案或電路。關閉後再次開啟，會留在上次的分頁。
- 「常見公式」可搜尋布林定律、德摩根、NAND／NOR 轉換、加減法器、選擇器、正反器及 K-Map 規則。側邊欄支援 Esc 關閉、方向鍵切換分頁與鍵盤焦點循環。
- 電路題可以從元件列拖入邏輯閘，或點選元件快速加入。每種閘使用對應的電路符號。
- 連線可從來源接點拖到目的接點，也可依序點選來源、目的接點。邏輯閘右上角常駐小垃圾桶可直接刪除該閘；導線選取後可使用刪除按鈕。選取後也可按 Delete 或 Backspace。
- 題目提供的輸入與輸出端也能個別拖曳。點擊 INPUT 元件內的 0／1 開關即可切換輸入，輸出結果顯示在 OUTPUT 元件內。
- 切換輸入即可即時觀察輸出：0 顯示藍灰、1 顯示青綠、未知訊號 X 顯示琥珀色與虛線。導線依來源訊號變色，元件依輸出訊號變色；邏輯閘的輸出值顯示在符號內。
- 闖關頁採分層深色介面，讓電路畫布、任務卡與提示保持清楚的視覺層級；高電位訊號會沿導線流動。輸入切換、接線及檢核有短音效，右上角喇叭按鈕可關閉音效，設定會保存在目前瀏覽器。
- 桌面版接線關卡會在視窗內顯示工作台和主要檢核按鈕；提示與詳解可在右側任務卡內捲動。窄螢幕保留底部固定的檢核按鈕。
- 按「逐列演示」可依序播放本關的輸入組合，查看每列的預期與實際輸出。演示中會暫停編輯；若有錯誤，結束後會停在第一組失敗輸入，並標示錯誤輸出。可按「停止演示」還原開始前的輸入狀態。
- 按「測試電路」會逐組檢查所有輸入；循序題則會檢查多個時間點。通關後主按鈕會變成「下一關」；修改電路或答案後需重新測試。
- 工作台上方有「復原／重做」，也可用 `Ctrl+Z`／`Ctrl+Shift+Z`（Mac 用 `⌘`）。新增、刪除、連線、移動、清空與輸入切換都能回到前一步；新操作會清除重做紀錄。
- 測試失敗時，工作台顯示第一組錯誤輸入及預期、實際輸出，並標亮對應輸出；循序題會標示失敗的時間步驟。
- 手機版底部固定測試按鈕。工作台有固定邊界，一般關卡最多放置 8 個元件，四變數 NAND 挑戰最多 12 個；拖曳元件離開可見區域時會移回畫布。「顯示全圖」可快速找回所有元件。自由探索工作台可產生目前電路的真值表。

## 中高難度題庫

新增 16 關，選單以「中階／高階」標示，原有關卡 ID 與瀏覽器進度仍可沿用。

- 布林代數：四變數格雷碼卡諾圖、無關項、SOP 選擇、二輸入 NAND 合成、NOR 的 POS 實作、BCD 七段顯示 b 段卡諾圖及接線。
- 組合電路：1～15 號碼分組的 G1、G0、連續位址解碼、雙輸出全減器。
- 循序邏輯：雙級移位、EN 致能暫存器、同步模 4 計數器、含非法循環的完整狀態表、四位元累加器事件推演。
- 沙盒挑戰：只用 NOR 實作 XOR。

題型參考使用者提供的 `109學年度第2學期_數位邏輯_期中考_題目.pdf`、`LOGIC2025A.pdf`、`LOGIC2026A.pdf`，並改編為互動練習；未上傳附件原檔。各題詳解註明改編來源。原考題的多輸入 NAND／NOR 在接線題中改為二輸入元件，提供可實作的分解步驟。

卡諾圖中 X 表示「規格不限制」；接線畫布中 X 表示「未知訊號」。自動檢核忽略目標的無關項，但仍驗證每組有效輸入與所有指定輸出；不要求唯一接法。循序題的檢核與演示皆從初始 0 狀態開始，正反器在同一時脈邊緣同時讀取舊狀態，RST 為高有效非同步清除。

## 檢查

```bash
npm run build
npm run test:logic
npm run smoke
npm run smoke:advanced
npm run smoke:reference
```

`smoke` 使用本機安裝的 Google Chrome，驗證答題與進度保存、電路求值、點選接線，以及桌面和手機版流程。

`smoke:advanced` 驗證新增接線題的 11 組參考電路與錯接反例、NOR 三值邏輯、有效輸入、非同步清除、同時取樣，以及新增題型的桌面與手機作答流程。

`smoke:reference` 驗證側邊欄的七種邏輯閘真值表、D 正反器的獨立示範、公式搜尋、鍵盤操作，以及查閱前後電路與學習進度保持一致。

## 實作結構

- `src/content.ts`：模組、原有 24 道題目，以及整合後的 40 道題庫與接線詳解。
- `src/advancedContent.ts`：16 道中高難度題目、參考真值表、時序測試與接線順序。
- `src/AdvancedTaskBoard.tsx`：四變數卡諾圖、狀態表與十六進位事件作答。
- `src/LogicReference.tsx`、`src/reference.ts`：側邊欄的邏輯閘互動介紹、真值表與可搜尋的常見公式。
- `src/logic.ts`：邏輯閘與 D 正反器求值、真值表與自動檢核。
- `src/GateSymbol.tsx`：AND、OR、XOR、NAND、NOR、NOT 與 D 正反器 SVG 符號。
- `src/Workbench.tsx`：拖放元件、接線、個別刪除、視角限制及即時輸入。
- `src/SignalEdge.tsx`：訊號導線及選取後的刪除工具列。
- `src/sound.ts`：可關閉的合成互動音效。
- `src/App.tsx`：首頁、闖關流程、評量回饋、進度與徽章。
- `src/styles.css`：桌面與手機版樣式。

學習進度保存在目前瀏覽器的 `localStorage`，不會跨裝置同步。自由探索工作台提供兩個輸入、一個輸出的組合邏輯；循序電路的 D 正反器練習位於循序邏輯模組。
